# Stage 40 — Source and attribution notes

- IELTS assessment terminology and task framing: IELTS public preparation/assessment resources. The app's 0–10 mission score is an internal practice metric, not an official band.
- Definition lookup: Free Dictionary API (`https://api.dictionaryapi.dev/`). Its data is requested at runtime; no Cambridge/Oxford definitions are redistributed.
- Uzbek translation lookup: MyMemory (`https://api.mymemory.translated.net/`) at runtime. Machine translation is not human-verified and can select the wrong sense.
- Cambridge/Oxford links open official dictionary pages for learner verification; they are not scraped into the ZIP.
- Collocation/grammar questions and pronunciation practice sentences added in Stage 40 are original IELTS Boost material.
- Bundled listening MP3s are synthetic practice generated from original IELTS Boost scripts, not official IELTS, Cambridge or British Council audio.
