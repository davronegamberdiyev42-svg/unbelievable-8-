# Sources and limitations

- IELTS official public preparation resources and public Writing/Speaking band descriptors are linked in the platform. The app does not reproduce full copyrighted Cambridge/IELTS tests.
- Bundled MP3s are original synthetic IELTS Boost practice scripts, not official IELTS or Cambridge recordings.
- English definitions/phonetics are fetched from an open Free Dictionary API where available; Oxford/Cambridge links are provided for checking.
- Uzbek machine translation is requested from MyMemory and must be sense-checked; it is not represented as a human-verified dictionary.
- Web Speech API `SpeechRecognition` is browser-dependent. Some Chrome implementations send audio to a remote recognition service and therefore need internet; the app has no bundled offline Whisper model.
