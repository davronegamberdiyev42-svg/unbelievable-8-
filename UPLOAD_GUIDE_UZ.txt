1) Samsung My Files → Downloads ichida 01_ROOT_FILES.zip ni top → Extract.
2) GitHub’da aynan unbelievable-8- repository bosh sahifasini och → Add file → Upload files.
3) Extract qilingan root ichidagi HAMMA fayl va papkalarni tanla. ZIP faylni o‘zini yuklama.
   index.html, manifest.webmanifest, sw.js, app-icon fayllari va .nojekyll root’da turishi kerak.
4) GitHub repository ichidagi audio/ papkasini och. 02_AUDIO_PART_1_OF_3.zip ni telefonda Extract qil;
   ichidagi 28 MP3 faylni audio/ ichiga yukla. Keyin 03 va 04 qismlarni ham xuddi shunday joyla.
5) Repository → Settings → Pages → Deploy from a branch → main → /(root) → Save.
6) Ochiladigan manzil: https://davronegamberdiyev42-svg.github.io/unbelievable-8-/
7) Sahifa yuklangach bir marta refresh qil. Settings → PWA readiness check’da manifest, icons,
   GitHub project scope va Service Worker qatorlarini tekshir.
8) Chrome ⋮ → Install app ko‘rinsa tanla. Oddiy Create shortcut tanlansa bu faqat browser shortcut bo‘lishi mumkin.
