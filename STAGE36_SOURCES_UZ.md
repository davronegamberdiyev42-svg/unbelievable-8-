# Stage 36 — rasmiy va tashqi manbalar

Quyidagi manbalar test formati, assessment mezonlari, talaffuz/transcript texnologiyasi va vocabulary lookup uchun ishlatiladigan havolalardir. Platformadagi kundalik prompt va mashqlar original IELTS Boost practice material hisoblanadi; manbalar to‘liq kitob nusxalarini yoki rasmiy imtihon materiallarini qayta tarqatish uchun ishlatilmaydi.

## IELTS rasmiy tayyorgarlik manbalari

- IELTS Academic sample test questions: https://ielts.org/take-a-test/preparation-resources/sample-test-questions/academic-test
- IELTS preparation resources: https://www.ielts.org/take-a-test/preparation-resources
- IELTS scoring in detail: https://ielts.org/take-a-test/your-results/ielts-scoring-in-detail
- Writing and Speaking band descriptors / criteria: https://ielts.org/take-a-test/preparation-resources

## Nashriyot resurslari

- Collins ELT audio resources (foydalanuvchida tegishli kitob/edition bo‘lishi talab qilinishi mumkin): https://collins.co.uk/pages/elt-elt-audio-resources
- Barron’s IELTS book resource hub: https://www.barronseduc.com/booksonline?search=IELTS
- Cambridge learner dictionary (definition/IPA tekshirish): https://dictionary.cambridge.org/
- Oxford Learner’s Dictionaries: https://www.oxfordlearnersdictionaries.com/

## Speaking transcript texnologiyasi

- MDN Web Speech API: https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API
- MDN SpeechRecognition: https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition

Browser SpeechRecognition hamma qurilma va tarmoqda bir xil ishlamaydi; ayrim browserlarda server-side recognition yoki internet kerak. Manual transcript fallback shu sababli qo‘shilgan. Pronunciation bahosi audio qayta tinglash va reviewer evidence talab qiladi.

## Vocabulary lookup

- Free Dictionary API: https://dictionaryapi.dev/
- MyMemory API documentation: https://mymemory.translated.net/doc/spec.php

API natijalari availability va usage limit’lariga bog‘liq. Machine translation kontekstga mos bo‘lmasligi mumkin; Cambridge/Oxford bilan tekshirish kerak.
